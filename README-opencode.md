# เชื่อมต่อ opencode เข้ากับ AI Gateway ของ 9Arm

ชุดคำสั่งนี้จะช่วยให้คุณใช้ **opencode** (โปรแกรม AI ช่วยเขียนโค้ดที่ทำงานในหน้าต่างเทอร์มินัล) พูดคุยกับ AI ของ **9Arm** ได้ง่ายๆ เพียงแค่กดรันสคริปต์ครั้งเดียว ก็พร้อมใช้งานทันที ไม่ต้องมานั่งตั้งค่าด้วยมือให้ปวดหัว

> ### 🙏 ขอบคุณเจ้าชายไอทีแห่งประเทศไทย — 9Arm
> สคริปต์ตัวนี้เชื่อมต่อกับ AI gateway ของ **9Arm (เจ้าชายไอทีแห่งประเทศไทย)**
> ถ้าใช้งานแล้วถูกใจ ช่วย **กดติดตาม (Subscribe)** เป็นกำลังใจ & เชียร์ค่าโทเค็น (token) ที่ใช้เลี้ยง AI ให้เค้าได้ต่อยอดไปเรื่อยๆ
>

## สิ่งนี้คืออะไร / เหมาะกับใคร

**opencode** คือ AI coding agent แบบโอเพนซอร์ส (เปิดเผยโค้ด ให้ใช้ฟรี) ที่ทำงานในเทอร์มินัล (หน้าต่างดำๆ สำหรับพิมพ์คำสั่ง) ช่วยคุณเขียน แก้ไข และอธิบายโค้ดได้ โดยคุณเลือกผู้ให้บริการโมเดลได้อย่างอิสระ และติดตั้งได้ง่ายๆ ด้วยคำสั่ง `npm install -g opencode-ai`

สคริปต์ในไฟล์ชุดนี้ทำหน้าที่เชื่อม opencode เข้ากับ AI gateway ของ **9Arm** โดยอัตโนมัติ เหมาะกับคนทั่วไปที่ไม่เก่งคอมพิวเตอร์ อยากใช้ AI ช่วยงานเขียนโค้ดโดยไม่ต้องมานั่ง configure อะไรเอง

## ต้องเตรียมอะไรก่อน

ก่อนทำทุกอย่าง **ต้องติดตั้ง claude-9arm ให้เสร็จก่อนเสมอ** เพราะตัวติดตั้งของ claude-9arm เป็นตัวสร้างไฟล์ token (รหัสประจำตัว) ขึ้นมา แล้ว agent ตัวอื่นๆ รวมถึง opencode จะเอาไฟล์ token อันนั้นมาใช้ร่วมกัน

ให้เปิดเทอร์มินัล (ดูวิธีในหัวข้อถัดไป) แล้วรัน:

- **Windows:** `install-claude-9arm.ps1`
- **macOS:** `install-claude-9arm-mac.sh`

นอกจากนี้ ต้องมี **Node.js LTS** (มาพร้อม npm) ติดตั้งไว้บนเครื่องก่อน ดาวน์โหลดได้ที่ https://nodejs.org หรือบน macOS ใช้คำสั่ง `brew install node` ก็ได้

## ขั้นตอนที่ 1 ดาวน์โหลดไฟล์

เลือกทำวิธีใดวิธีหนึ่ง เพื่อดาวน์โหลดไฟล์ชุดนี้ออกมา

**วิธี A ดาวน์โหลดเป็น ZIP (ง่ายสุดสำหรับมือใหม่)**
1. เปิด https://github.com/thaigqsoft/claude-9arm ในเว็บเบราว์เซอร์
2. กดปุ่มเขียว **Code**
3. กด **Download ZIP**
4. แตกไฟล์ ZIP ออกมา (คลิกขวาแล้วเลือก "แตกไฟล์ / Extract All")
5. จำที่อยู่ของโฟลเดอร์ที่แตกไฟล์ไว้ให้ดี

**วิธี B ใช้คำสั่ง git**
1. เปิดเทอร์มินัล
2. พิมพ์คำสั่ง: `git clone https://github.com/thaigqsoft/claude-9arm.git`

จากนั้นเปิดเทอร์มินัลแล้ว **cd เข้าโฟลเดอร์ที่ดาวน์โหลดมา** ก่อนเสมอ (กฎเหล็ก: ก่อนพิมพ์คำสั่งอะไรก็ตาม ต้องเข้าโฟลเดอร์นี้ให้ได้ก่อน):

- **Windows:** เปิด File Explorer เข้าโฟลเดอร์ที่แตกไฟล์ไว้ > คลิกช่อง address bar (แถบที่อยู่) ด้านบน > พิมพ์ `powershell` แล้วกด Enter จะเปิด PowerShell ตรงโฟลเดอร์นั้นให้เลย
- **macOS:** เปิดแอป Terminal แล้วพิมพ์ `cd ` (พิมพ์คำว่า cd ตามด้วยช่องว่าง 1 เคาะ) แล้วลากโฟลเดอร์จาก Finder มาวางในหน้าต่าง Terminal แล้วกด Enter

## ขั้นตอนที่ 2 ติดตั้ง

เมื่อ cd เข้าโฟลเดอร์ที่ดาวน์โหลดมาแล้ว ให้ติดตั้งตามระบบของคุณ โดยแยก Windows กับ macOS

**Windows** — เปิด PowerShell ตรงโฟลเดอร์ แล้วพิมพ์:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-opencode-9arm.ps1
```

**macOS** — เปิด Terminal ตรงโฟลเดอร์ แล้วพิมพ์:
```bash
bash install-opencode-9arm-mac.sh
```

**หมายเหตุ:** ถ้าคุณติดตั้ง opencode เองไว้แล้ว และไม่อยากให้สคริปต์ติดตั้งซ้ำ ฝั่ง macOS ใส่ `--skip-install` ต่อท้ายได้ เช่น `bash install-opencode-9arm-mac.sh --skip-install`

ระหว่างรันสคริปต์ คุณจะเห็นข้อความบนจอแสดงความคืบหน้า เช่นการติดตั้ง opencode และการเขียนไฟล์ตั้งค่า เมื่อเสร็จแล้วสคริปต์จะพิมพ์วิธีใช้งานให้ดู (สคริปต์รันซ้ำได้กี่ครั้งก็ได้ ไม่ทำให้พัง)

## ขั้นตอนที่ 3 ใช้งานจริง

สคริปต์จะเขียน **provider** ชื่อ `9arm` ลงในไฟล์ `~/.config/opencode/opencode.json` โดยอ้างอิง token จาก `~/.claude-9arm/token` ให้อัตโนมัติ แล้วคุณก็เริ่มถาม AI ได้เลย โดย cd เข้าโฟลเดอร์งานของคุณก่อน แล้วพิมพ์คำสั่งตามนี้

```bash
opencode --model 9arm/qwen3.8-27b-fp8 "คำถามของคุณ"
opencode --model 9arm/deepseek-v4-flash-0731 "คำถามของคุณ"
```

### ตั้งเป็นโมเดลเริ่มต้น (ไม่ต้องพิมพ์ `--model` ทุกครั้ง)

ถ้าอยากได้โมเดลเริ่มต้นเป็นตัวเดิมทุกครั้ง ให้เปิดไฟล์ `~/.config/opencode/opencode.json` แล้วเพิ่มบรรทัดนี้ลงไป:

```json
{ "model": "9arm/qwen3.8-27b-fp8" }
```

### ตารางโมเดลที่ใช้ได้

| Model ID | ชื่อโมเดล |
|---|---|
| `qwen3.8-27b-fp8` | Qwen 3.8 27b FP8 |
| `deepseek-v4-flash-0731` | DeepSeek V4 Flash 0731 |

## เช็คว่าใช้ได้จริงไหม

ลองพิมพ์คำสั่งวิธีใช้งานในหัวข้อที่แล้ว เช่น `opencode --model 9arm/qwen3.8-27b-fp8 "สวัสดี"` แล้วดูว่า AI ตอบกลับมา ถ้าได้คำตอบกลับมาแสดงว่าเชื่อมต่อสำเร็จและพร้อมใช้งานแล้ว

## ถ้าติดปัญหา

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ไม่พบไฟล์ token / token file not found | ยังไม่ได้ติดตั้ง claude-9arm หรือยังไม่ได้สร้าง token | กลับไปรันสคริปต์ติดตั้งของ claude-9arm ก่อน (`install-claude-9arm.ps1` บน Windows / `install-claude-9arm-mac.sh` บน macOS) เพื่อสร้างไฟล์ token |
| model not found / 9arm/... | ไม่พบ provider หรือพิมพ์ชื่อโมเดลผิด | เช็คว่ามี provider `9arm` อยู่ในไฟล์ `~/.config/opencode/opencode.json` แล้ว และลองพิมพ์โมเดลตามตารางข้างบนให้ตรงเป๊ะ |
| ไม่สั่งได้ / permission denied | ไม่ได้ cd เข้าโฟลเดอร์ที่ดาวน์โหลดมา | กลับไป cd เข้าโฟลเดอร์ก่อน แล้วรันคำสั่งติดตั้งใหม่ |
| gateway เงียบ / ช้า ไม่ตอบ | gateway อาจชั่วคราวลงหรือเน็ตขัดข้อง | รอสักครู่แล้วลองใหม่ เช็คอินเทอร์เน็ตว่าทำงานปกติ |
| สคริปต์ไม่รู้จักคำสั่ง powershell / bash | เปิดผิดโปรแกรม หรือไม่ได้อยู่ในโฟลเดอร์ | ตรวจว่าเปิด PowerShell (Windows) หรือ Terminal (macOS) และอยู่ที่โฟลเดอร์ที่ดาวน์โหลดมา |
| ไม่เห็นโปรแกรม opencode หลังรันเสร็จ | การติดตั้ง npm ล้มเหลว | ติดตั้ง Node.js LTS ให้ครบจาก https://nodejs.org แล้วรันสคริปต์อีกครั้ง |

## คำถามที่พบบ่อย

**ต้องติดตั้ง claude-9arm ด้วยไหม?**
จำเป็นต้องติดตั้งก่อน เพราะเป็นตัวสร้างไฟล์ token ที่ใช้ร่วมกัน ถ้าไม่มี token จะเชื่อมต่อไม่ได้

**token เก็บไว้ที่ไหน?**
Windows เก็บที่ `%USERPROFILE%\.claude-9arm\token` และ macOS เก็บที่ `~/.claude-9arm/token` โดย token จะออกให้โดยเจ้าของ gateway เท่านั้น ห้ามแชร์ต่อ

**ใช้ทั้ง macOS และ Windows ได้ไหม?**
ได้ มีสคริปต์แยกกันสองตัว ตามระบบที่คุณใช้

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | ตำแหน่ง | หน้าที่ |
|---|---|---|
| `install-opencode-9arm.ps1` | โฟลเดอร์ที่ดาวน์โหลดมา | สคริปต์ติดตั้งสำหรับ Windows |
| `install-opencode-9arm-mac.sh` | โฟลเดอร์ที่ดาวน์โหลดมา | สคริปต์ติดตั้งสำหรับ macOS |
| `opencode.json` | `~/.config/opencode/opencode.json` | ไฟล์ตั้งค่าของ opencode (เขียนโดยสคริปต์ติดตั้ง) |
| `token` | `~/.claude-9arm/token` | token ของ gateway (สร้างโดย claude-9arm เป็นตัวเดียวกับที่ใช้ร่วมกัน) |
