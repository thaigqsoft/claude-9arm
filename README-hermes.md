# Hermes + 9Arm Gateway — คู่มือติดตั้งสำหรับทุกคน

คู่มือนี้จะช่วยให้คุณติดตั้ง **Hermes** (ผู้ช่วย AI ที่ทำงานในหน้าต่างดำๆ หรือเทอร์มินัล) ให้เชื่อมต่อกับ **9Arm Gateway** ได้ด้วยตัวเอง แม้คุณไม่เก่งคอมพิวเตอร์ก็ตาม ขอแค่ทำตามทีละขั้นตอนในคู่มือนี้ก็พอครับ

> ถ้าใช้งานแล้วถูกใจ ช่วย **กดติดตาม (Subscribe)** เป็นกำลังใจ & เชียร์ค่าโทเค็น (token) ที่ใช้เลี้ยง AI ให้เค้าได้ต่อยอดไปเรื่อยๆ

## สิ่งนี้คืออะไร / เหมาะกับใคร

**Hermes** คือ AI agent (ผู้ช่วย AI) จากทีม **Nous Research** ที่ใช้เปิดใช้งานใน **เทอร์มินัล** (Terminal หรือหน้าต่างดำๆ ที่ใช้พิมพ์คำสั่งในคอมพิวเตอร์) เอกสารของ Hermes อยู่ที่ https://hermes-agent.nousresearch.com

เจ้า Hermes นี้ทำอะไรได้บ้าง?

- ตอบคำถามเหมือนแชทบอททั่วไป
- ช่วยเขียนโค้ด แก้ไขไฟล์ หรือทำงานต่างๆ ในคอมพิวเตอร์ได้
- คุยกับคุณแบบโต้ตอบได้ตลอดการสนทนา
- ใช้ได้ทั้งงานง่ายๆ ไปจนถึงงานที่ต้องใช้ความสามารถของ AI

โดยปกติ Hermes จะเรียกใช้โมเดล AI ผ่านบริการของตัวเอง แต่คู่มือนี้จะช่วยให้ Hermes เรียกใช้โมเดล AI **ผ่าน 9Arm Gateway** แทน

คู่มือนี้เหมาะกับ **คนที่ไม่เก่งคอมพิวเตอร์** ที่อยากได้ผู้ช่วย AI มาใช้งานบนเครื่องของตัวเอง โดยไม่ต้องเขียนโค้ดหรือตั้งค่าอะไรยุ่งยาก

## ต้องเตรียมอะไรก่อน

ก่อนจะติดตั้ง Hermes ต้องเตรียมสิ่งเหล่านี้ให้พร้อมก่อนครับ:

1. **ติดตั้ง claude-9arm ให้เสร็จก่อนเสมอ** — นี่เป็นเรื่องสำคัญมาก เพราะตัวติดตั้งของ claude-9arm เป็นตัวสร้างไฟล์ **token** (เหมือนรหัสผ่าน) ที่ agent หลายตัวใช้ร่วมกัน ไฟล์นี้ถูกเก็บไว้ที่ Windows: `%USERPROFILE%\.claude-9arm\token` / macOS: `~/.claude-9arm/token`
   - Windows ใช้คำสั่งติดตั้ง `install-claude-9arm.ps1`
   - macOS ใช้คำสั่งติดตั้ง `install-claude-9arm-mac.sh`
2. **ต้องมี Node.js LTS** (มาพร้อม npm) — ดาวน์โหลดได้ที่ https://nodejs.org หรือบน macOS จะใช้คำสั่ง `brew install node` ก็ได้
3. มีเครื่องคอมพิวเตอร์ที่ใช้งานได้ตามปกติ — ทั้ง **Windows** และ **macOS**

> ⚠️ **ถ้ายังไม่ได้ติดตั้ง claude-9arm** ให้กลับไปติดตั้งให้เสร็จก่อน แล้วค่อยมาทำตามขั้นตอนถัดไปครับ เพราะถ้าไม่มีไฟล์ token ตัวติดตั้ง Hermes จะทำงานไม่สำเร็จ

## ขั้นตอนที่ 1 ดาวน์โหลดไฟล์

ให้ดาวน์โหลดชุดไฟล์ทั้งหมดของ claude-9arm มาก่อน โดยเลือกได้ 2 วิธี:

### วิธี A — ดาวน์โหลดเป็น ZIP (แบบไม่ต้องใช้คำสั่ง)

1. เปิดเว็บเบราว์เซอร์เข้าไปที่ https://github.com/thaigqsoft/claude-9arm
2. กดปุ่มเขียว **Code** ด้านบนขวา
3. เลือก **Download ZIP**
4. แตกไฟล์ ZIP ออกมา (คลิกขวาแล้วเลือก Extract / แตกไฟล์)
5. **จำที่อยู่ของโฟลเดอร์ที่แตกไฟล์ไว้** ให้ดี เพราะขั้นตอนต่อไปต้องเข้าไปในโฟลเดอร์นี้

### วิธี B — ใช้คำสั่ง git

1. เปิดเทอร์มินัล (ดูวิธีเปิดในหัวข้อถัดไป)
2. พิมพ์คำสั่งตามหัวข้อถัดไปให้ cd เข้าโฟลเดอร์ที่ต้องการก่อน แล้วพิมพ์คำสั่งนี้:

```bash
git clone https://github.com/thaigqsoft/claude-9arm.git
```

### เปิดเทอร์มินัลแล้ว "cd" เข้าไปในโฟลเดอร์

**สำคัญ:** ทุกครั้งที่จะพิมพ์คำสั่ง ต้องเข้าไปในโฟลเดอร์ที่แตกไฟล์ไว้ก่อนเสมอ (เรียกว่า "cd เข้าโฟลเดอร์")

- **Windows:** เปิด **File Explorer** เข้าไปในโฟลเดอร์ที่แตกไฟล์ไว้ > คลิกที่ช่อง address bar (แถบที่อยู่) ด้านบน > พิมพ์ `powershell` แล้วกด **Enter** ซึ่งจะเปิดหน้าต่าง PowerShell ขึ้นมาตรงโฟลเดอร์นั้นให้เลย
- **macOS:** เปิดแอป **Terminal** แล้วพิมพ์ `cd ` (มีเว้นวรรคหลัง `cd` นะครับ) แล้วลากโฟลเดอร์จาก Finder มาวางในหน้าต่าง Terminal แล้วกด **Enter**

## ขั้นตอนที่ 2 ติดตั้ง

เมื่อ cd เข้าไปในโฟลเดอร์ที่แตกไฟล์ไว้แล้ว ให้ติดตั้งตามระบบปฏิบัติการที่คุณใช้

### สำหรับผู้ใช้ Windows

พิมพ์คำสั่งนี้ลงในหน้าต่าง PowerShell แล้วกด **Enter**:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-hermes-9arm.ps1
```

ระหว่างติดตั้งสคริปต์จะจัดการตั้งค่าต่างๆ ให้อัตโนมัติ:

1. ตรวจสอบว่าไฟล์ token ของ claude-9arm มีอยู่หรือไม่
2. ติดตั้ง Hermes และตั้งค่าให้เรียบร้อย
3. เขียนค่าตั้งค่า (config) ลงในไฟล์ `~/.hermes/.env`

เมื่อเสร็จแล้วควรเห็นข้อความแจ้งว่าเสร็จสมบูรณ์ (Success / Done) บนหน้าจอ

### สำหรับผู้ใช้ macOS

พิมพ์คำสั่งนี้ลงในหน้าต่าง Terminal แล้วกด **Enter**:

```bash
bash install-hermes-9arm-mac.sh
```

> 💡 **เคล็ดลับ:** ถ้าคุณติดตั้ง Hermes ไว้เองแล้วก่อนหน้านี้ และไม่อยากให้สคริปต์ติดตั้งซ้ำ (เช่น อยากสงวนเวอร์ชันที่ติดตั้งไว้) ให้ใส่ `--skip-install` ต่อท้ายคำสั่งด้วยครับ

```bash
bash install-hermes-9arm-mac.sh --skip-install
```

สคริปต์จะจัดการตั้งค่าต่างๆ ให้อัตโนมัติ โดยจะอ่าน token จากโฟลเดอร์ claude-9arm แล้วเขียนตั้งค่า (config) ลงในไฟล์ `~/.hermes/.env` ให้เสร็จเรียบร้อย (สำหรับผู้ใช้ Windows สคริปต์จะจัดการให้เองโดยอัตโนมัติ)

> 💡 **เคล็ดลับ:** สคริปต์นี้รันซ้ำได้หลายครั้ง ไม่เกิดอันตราย ถ้ารันแล้วเจอข้อความผิดพลาด ลองรันใหม่อีกครั้งได้ครับ

**ถ้ารันแล้วเจอข้อความ "ไม่พบ token file"** — แปลว่ายังไม่ได้ติดตั้ง claude-9arm ให้กลับไปทำหัวข้อ **ต้องเตรียมอะไรก่อน** ก่อนครับ

## ขั้นตอนที่ 3 ใช้งานจริง

เมื่อติดตั้งเสร็จเรียบร้อย เริ่มใช้งานได้เลย:

1. เปิดเทอร์มินัล (Terminal) แล้วพิมพ์คำสั่ง `hermes` แล้วกด **Enter** เพื่อเปิดโปรแกรม Hermes
2. พิมพ์คำสั่ง `/model` เพื่อเข้าไปเลือกโมเดล (Model) และก็อาจต้องเลือก provider (ผู้ให้บริการโมเดล)
3. เลือก provider เป็น **`openai-api`**
4. เลือกโมเดล AI ตามที่ต้องการจาก 2 ตัวนี้:
   - **`qwen3.8-27b-fp8`**
   - **`deepseek-v4-flash-0731`**
5. เสร็จแล้วก็พิมพ์คำถามหรือสิ่งที่ต้องการ แล้วกด **Enter** ก็ใช้งานได้เลย

สคริปต์จะเขียนค่าให้ Hermes รู้จัก gateway โดยอัตโนมัติ ผ่านตัวแปร (ค่าที่ตั้งไว้ในไฟล์ config):

- `OPENAI_API_KEY` — ค่า key ที่ใช้ในการเชื่อมต่อ (นำมาจากไฟล์ token ของ claude-9arm)
- `OPENAI_BASE_URL=https://gateway.9arm.co/v1` — ที่อยู่ของ gateway แบบ OpenAI-compatible

ทั้งสองค่านี้ถูกเขียนลงในไฟล์ `~/.hermes/.env` ซึ่งเป็น provider ชื่อ **`openai-api`** ของ Hermes

### ตารางโมเดลที่เลือกได้

| ชื่อโมเดล | วิธีเลือก |
|---|---|
| `qwen3.8-27b-fp8` | พิมพ์ `/model` > เลือก provider `openai-api` > เลือก `qwen3.8-27b-fp8` |
| `deepseek-v4-flash-0731` | พิมพ์ `/model` > เลือก provider `openai-api` > เลือก `deepseek-v4-flash-0731` |

### ตัวอย่างการใช้

เปิดเทอร์มินัลแล้วพิมพ์:

```bash
hermes "สวัสดี ช่วยแนะนำวิธีเขียนโค้ดง่ายๆ หน่อย"
```

จากนั้นภายในโปรแกรม Hermes ใช้คำสั่ง `/model` เลือก provider เป็น `openai-api` แล้วเลือกโมเดลตามที่ต้องการ ก็เป็นอันเสร็จแล้วครับ

## เช็คว่าใช้ได้จริงไหม

เมื่อติดตั้งเสร็จ ลองเช็คว่าทุกอย่างทำงานถูกต้องตามนี้:

1. เปิดเทอร์มินัล แล้วพิมพ์ `hermes` แล้วกด **Enter** — ควรเห็นโปรแกรม Hermes เปิดขึ้นมา
2. พิมพ์ `/model` แล้วกด **Enter** — ควรเห็นรายการ provider และโมเดลขึ้นมา
3. เลือก provider เป็น `openai-api` และเลือกโมเดล เช่น `deepseek-v4-flash-0731`
4. พิมพ์คำถามง่ายๆ เช่น `1+1 เท่ากับเท่าไร` แล้วกด **Enter** — ถ้าได้คำตอบจาก AI แปลว่าการเชื่อมต่อกับ gateway สำเร็จแล้ว

> 💡 **ข้อสังเกต:** ถ้าเปิดเทอร์มินัลตรงโฟลเดอร์อื่นแล้วพิมพ์ `hermes` ไม่เจอคำสั่ง ให้ลองปิดแล้วเปิดเทอร์มินัลใหม่ หรือรันสคริปต์ติดตั้งซ้ำอีกครั้ง

## ถ้าติดปัญหา

ถ้าเจอปัญหาขณะใช้งาน ลองเช็คตามตารางนี้ก่อนครับ:

| อาการที่พบ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เจอข้อความ "ไม่พบ token file" | ยังไม่ได้ติดตั้ง claude-9arm จึงยังไม่มีไฟล์ token | ให้กลับไปติดตั้ง claude-9arm ให้เสร็จก่อน แล้วค่อยมาทำขั้นตอนติดตั้ง Hermes ใหม่ |
| เลือก provider `openai-api` แล้วไม่โผล่ | ไฟล์ `~/.hermes/.env` อาจถูกเขียนไม่สมบูรณ์ | ตรวจสอบว่าไฟล์ `~/.hermes/.env` มีค่า `OPENAI_API_KEY` และ `OPENAI_BASE_URL=https://gateway.9arm.co/v1` หรือไม่ ถ้าไม่มีให้รันตัวติดตั้งใหม่ |
| gateway เงียบหรือช้ามาก | gateway อาจติดขัดชั่วคราว (ระบบกำลังปรับปรุง) | ให้รอสักครู่ แล้วลองใช้งานใหม่อีกครั้ง |
| พิมพ์ `hermes` แล้วไม่เจอคำสั่ง | โปรแกรมยังไม่ได้อยู่ใน path หรือติดตั้งไม่จบ | ลองปิดแล้วเปิดเทอร์มินัลใหม่ ถ้ายังไม่หายให้รันสคริปต์ติดตั้งซ้ำอีกครั้ง |
| บอก token ไม่ถูกต้องหรือเชื่อมต่อไม่ได้ | ค่า token ใน `~/.hermes/.env` เก่าหรือไม่ตรงกัน | รันตัวติดตั้ง claude-9arm เพื่อสร้าง token ใหม่ (ถ้าจำเป็น) แล้วรันตัวติดตั้ง Hermes ซ้ำ |
| อื่นๆ ไม่ตรงกับตาราง | สาเหตุไม่ชัดเจน | ลองปิดแล้วเปิด Hermes ใหม่ หรือรันตัวติดตั้งซ้ำอีกครั้ง |

## คำถามที่พบบ่อย

**Q: ทำไมต้องติดตั้ง claude-9arm ก่อนเป็นคนแรก?**
A: เพราะตัวติดตั้งของ claude-9arm เป็นตัวสร้างไฟล์ token ที่ Hermes นำไปใช้ร่วมกัน ถ้าไม่มีไฟล์นี้ Hermes จะไม่สามารถเชื่อมต่อกับ gateway ได้ครับ

**Q: ต้องมี Node.js ด้วยหรือเปล่า?**
A: ใช่ครับ ต้องมี Node.js LTS (มาพร้อม npm) ดาวน์โหลดที่ https://nodejs.org หรือบน macOS ใช้ `brew install node` ก็ได้ครับ

**Q: ถ้ามี token อยู่แล้วแต่ยังไม่ได้ติดตั้ง claude-9arm ทำได้ไหม?**
A: ยังไงก็ต้องติดตั้ง claude-9arm ให้เสร็จก่อนเสมอครับ เพราะไฟล์ token ถูกสร้างและเก็บไว้โดยตัวติดตั้งนั้น

**Q: เลือกโมเดลไหนดีระหว่าง qwen กับ deepseek?**
A: แล้วแต่ที่คุณชอบได้เลยครับ ทั้งสองตัวนี้ใช้ได้ผ่าน gateway นี้ โดยเลือกผ่านคำสั่ง `/model` ภายใน Hermes

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | ตำแหน่ง | ทำหน้าที่ |
|---|---|---|
| `install-hermes-9arm.ps1` | โฟลเดอร์ claude-9arm ที่ดาวน์โหลดมา | ตัวติดตั้ง Hermes สำหรับ Windows |
| `install-hermes-9arm-mac.sh` | โฟลเดอร์ claude-9arm ที่ดาวน์โหลดมา | ตัวติดตั้ง Hermes สำหรับ macOS |
| `.env` | `~/.hermes/.env` | ไฟล์ตั้งค่า (config) ของ Hermes — สคริปต์เขียนค่า `OPENAI_API_KEY` และ `OPENAI_BASE_URL=https://gateway.9arm.co/v1` ให้อัตโนมัติ |
| `token` | Windows: `%USERPROFILE%\.claude-9arm\token` / macOS: `~/.claude-9arm/token` | รหัสผ่าน (token) สำหรับเชื่อมต่อ gateway — สร้างโดยตัวติดตั้ง claude-9arm ใช้ร่วมกันกับ agent หลายตัว |

> ⚠️ **ข้อควรระวัง:** ไฟล์ token เป็นความลับ ไม่ควรแชร์หรือเอาไปโพสต์ให้ใครดูเด็ดขาด เพราะถ้าหลุดไป คนอื่นอาจเอาไปใช้ได้ ห้ามแชร์ไฟล์นี้ต่อโดยเด็ดขาดครับ
